# 3D Garment Models Directory

Drop your production GLB files here! The asset loader will automatically detect them by file name and replace the procedural garment geometry with zero code changes.

### Supported File Names:
- `varsity-jacket.glb`
- `heavyweight-hoodie-oatmeal.glb`
- `piped-pullover-navy.glb`
- `chunky-knit-burgundy.glb`
- `mohair-striped-cardigan.glb`
- `washed-field-jacket.glb`
- `wide-leg-denim.glb`
- `chore-work-jacket.glb`
- `fleece-hoodie-heather.glb`
- `shadow-plaid-overshirt.glb`

Each model should be centered at `(0, 0, 0)` with the hanger attachment point at the top.
